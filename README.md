# Vitruvium

Заготовка игровой системы для Foundry VTT 14.369.

## Установка через Foundry VTT

В Setup перейдите в **Game Systems → Install System**, вставьте в поле **Manifest URL** и нажмите Install:

`https://raw.githubusercontent.com/Fragen2510/Vitruvium/refs/heads/main/system.json`

После установки выберите **Vitruvium** при создании мира. В качестве альтернативы систему можно установить вручную: распаковать архив репозитория в `Data/systems/vitruvium`.

Настройки мира позволяют менять максимум кубиков, максимум характеристики и границы отношений. Аспекты хранятся как самостоятельные Items типа `aspect`; изменять их разрешено только мастеру и ассистентам. Статусы также являются Items и могут быть вложенными в персонажа или существовать отдельно в мире.

Особый кубик использует грань d6 так: 1–3 = 0 успехов, 4–5 = 1 успех, 6 = 2 успеха. Панель броска хранит преимущества и помехи раздельно в пределах 0–2 и взаимно сокращает их при броске.
Dice Tray позволяет менять пул кубиков, преимущество/помеху и трату вдохновения кнопками «−/+»; одно вдохновение добавляет один d6 в исходный пул, который ограничен настройкой мира. После броска вдохновение также можно тратить на дополнительные d6 без ограничения исходного пула или на автоматические успехи числом, равным уровню выбранного домена. Очки списываются только после успешной публикации/обновления броска. Проверка сложности не выполняется.

## Dice So Nice

Интеграция необязательная. Если Dice So Nice включён, а `assets/dice/vitruvium-d6.glb` установлен, Vitruvium зарегистрирует свой DiceSystem и d6-пресет. Обычные броски передаются модулю через `ChatMessage.rolls`; бонусный d6 после броска анимируется отдельно. Пока GLB отсутствует, используется стандартный вид d6 Dice So Nice, а броски Vitruvium продолжают работать без модуля.

Требования к будущей модели описаны в [`assets/dice/README.md`](assets/dice/README.md).

Лист персонажа открывается в компактном режиме просмотра: редактирование характеристик и карточек включается отдельно для нужного блока, а изменения сохраняются кнопкой «Сохранить». Вдохновение ограничено диапазоном 0–6. Ресурсы персонажа хранятся в `system.resources` и включают название, изображение, описание, текущее и максимальное значения; быстрые кнопки «−/+» меняют текущий запас с сохранением в пределах 0–максимум.

Для НПС используется отдельный лист с базовыми кубами атаки и защиты, значением блока и способностями. Каждая способность задаёт число бонусных d6; её кнопки бросают базовый пул атаки или защиты с этой прибавкой. Фотографии загружаются в папку текущего мира и сохраняются как файловые пути, совместимые с валидацией Foundry 14.
